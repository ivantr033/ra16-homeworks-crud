## 🚀 Архитектурные особенности и оптимизации

Приложение разработано в соответствии с современными стандартами разработки на React 19:

1. **Безопасная обработка ошибок (No-Any Catch):** В соответствии со строгими правилами линтинга TypeScript блоки `catch(err)` типизированы через безопасный тип `unknown`. Проверка типа осуществляется через валидацию инстанса `err instanceof Error`, что гарантирует типобезопасность без использования подавляющего типа `any`.
2. **Контроль каскадных рендеров в React 19:** Вызов хука загрузки данных в `useEffect` защищен с помощью локального флага монтирования `isMounted`. Это предотвращает возникновение каскадных ре-рендеров (*cascading renders*) при инициализации асинхронных потоков на этапе первоначального вывода компонента в DOM.
3. **Паттерн Неконтролируемой Формы:** Сбор данных текстового поля переведен на нативный интерфейс `FormData` с автоматическим сбросом буфера через `currentTarget.reset()`. Это исключает посимвольный ре-рендеринг формы при вводе текста, минимизируя нагрузку на CPU.
4. **Адаптивная верстка текста (Anti-Overflow):** Для предотвращения деформации карточек при вводе аномально длинных слов (или URL-ссылок без пробелов) для параграфов внедрено CSS-свойство `overflowWrap: 'anywhere'`. Это обеспечивает адаптивный перенос строк точно по границе контейнера.

## 🛠️ Технологический стек

* **Frontend:** React 19 (Функциональные компоненты, Асинхронные стейты)
* **Язык:** TypeScript 5+ (Синтетические события, безопасные типы ошибок `unknown`)
* **Бэкенд:** Node.js, Express, Cors, Body-Parser
* **Сборщик:** Vite 8
* **CI/CD:** GitHub Actions (автоматический деплой ветки `gh-pages`)

## 🔧 Локальное развертывание, установка и запуск

Для полноценного тестирования приложения необходимо одновременно запустить локальный бэкенд-сервер и фронтенд-часть.

### Шаг 1: Запуск бэкенд-сервера (Backend)

1. Перейдите в каталог с серверной частью (каталог `backend` проекта):

    ```bash
    cd backend
    ```

2. Установите зависимости сервера:

   ```bash
   npm install
   ```

3. Запустите сервер (он начнет работу на порту `7070`):

   ```bash
   npm start
   ```

### Шаг 2: Запуск фронтенд-приложения (React + Vite)

1. Откройте **второй терминал** в корневом каталоге фронтенд-проекта (`ra16-homeworks-crud`):

   ```bash
   npm install --legacy-peer-deps
   ```

2. Запустите локальный сервер разработки:

   ```bash
   npm run dev
   ```

3. Откройте адрес в браузере (обычно [http://localhost:5173](http://localhost:5173)).

### Шаг 3: Сборка проекта (Production build)

Для генерации оптимизированного статического пакета выполните:

```bash
npm run build
```
